## 1. 第3章の芯

- **作ったもので、自然を読む**。第2章で、南の島の粘土の器が夜を照らした。第3章では、自分たちで焼いた壺・タール・竹で道具を作り、その道具で空の変化を前もって知ろうとする。「AI × 科学開拓」がいちばん分かりやすく見える章になる。
- **懸かっているものは本物**。見立ては外れることがある（空振り・見逃し）。外れたら、ランタンは見立てを直す（ADR 0006 の「仮説は本物の結果でしか確定しない」）。嵐は記録どおりに来るので、いつ当たるかは島と季節で変わる。
- **嵐の場面とつながる**。嵐はライブでいちばん強い場面の一つ（PROGRAM.md §4 の順位1）。「天気の壺が知らせ、嵐の前に筏を引き上げた」は、第1章の筏・第2章の器・第3章の道具が一つにつながる画になる。
- 気をつけること：**試験用の気圧計で、ランタンは第1・2章のうちから読んでいる**。その気圧計で第1・2章のうちに当たることがあれば、「天気を読めるか」はもう答えが出ている。第3章の問いは「**自分たちの壺で**」に置く。

## 2. 案

| | A：作る章 | **B：読む章（勧める、測りしだい）** | C：二つに分ける |
|---|---|---|---|
| 名前（左上） | `空をはかる壺` | **`天気を読む`** | 第3章 A、第4章 B |
| 問い | 「自分たちの壺で、空の重さをはかれるか」 | **「嵐が来る前に、気づけるか」** | — |
| 道のり | `炭 ・ タール ・ 封じた壺 ・ 竹の管 ・ 天気の壺` | **`炭 ・ タール ・ 封じた壺 ・ 天気の壺 ・ 嵐の前に`** | — |
| 終わり | 天気の壺が置かれ、初めて読まれたとき（`weather-pot`） | **天気の壺の見立てが初めて当たったとき**（管の水が上がり、そのあと1日のうちに嵐が来た） | — |
| 終わりの札 | 「自分たちの壺で、空の重さをはかった」 | **「天気の壺が、嵐を前もって知らせた」**。その嵐の前に備えたなら「天気の壺が知らせ、嵐の前に筏を引き上げた」など（備えた事実があるときだけ） | — |
| 長さ（見立て） | 約6〜12日（9日目から15〜21日目） | 天気の壺のあと、次の嵐まで。**島の季節しだい**（測りで決める） | それぞれ1〜2週 |
| よい所 | 終わりが確か。第2章と同じ「作ったものが働いた」 | 本物の懸け。島ごとに答え（何日目・何度めの嵐）が変わる。見立てが外れる場面も見どころになる | 両方のよい所 |
| 気になる所 | 終わりが静か（置いて読んだだけ）。懸けが弱い | 嵐の少ない季節に壺ができると、章が長くなる | 章が増え、1つずつが短い |

- **勧める形**：B。ただし、科学班の測りで、天気の壺ができてから最初の当たりまでが長い（目安：章の長さが3週間を超える）なら C にする。
- 第3章の始まり：第2章の終わりの札の1分後（第2章と同じ）。
- 続けている島：章が始まる前に天気の壺がもうある島では、第3章を出さない（第2章の #198 と同じ扱い）。
- 道のりの「済んだ」は、世界の事実で決める（名前と境は本体・科学班）。炭＝炭が初めてとれた、タール＝木タールが初めてとれた、封じた壺＝タールで封じた壺が初めてできた、天気の壺＝`weather-pot`、嵐の前に＝見立てが初めて当たった。

## 3. 科学班に測ってほしいこと

1. **新しい島で、12月に始めたとき**（例：12/1 と 12/5 に始める。AI なしと代わりの頭、いくつかの seed）：
   - 炭・タール・封じた壺・竹の管・天気の壺の時刻
   - 天気の壺の見立てが**初めて当たる時刻**。それまでの空振り・見逃しの数
   - そのころの島の季節と、嵐の数
2. **試験用の気圧計は、第1・2章（9日目まで）のうちに当たるか**。当たるなら、第3章の問いは「自分たちの壺で」に置く（§1）。
3. **当たった嵐の前に、住人が備えたか**（筏を引き上げた・食べ物を蓄えた、など）。札の「嵐の前に筏を引き上げた」を、世界の事実で言えるか。
4. 天気の壺の見立てを、試みの行（PROGRAM.md §1）に出せるか（本体）。
